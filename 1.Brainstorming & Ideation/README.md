## Problem Statement

Many people find it difficult to create a suitable workout routine according to
their personal fitness goals, age, weight and preferred workout intensity.

Users may also need different routines as their preferences and requirements
change.

FitBuddy solves this problem by using Generative AI to create personalized
fitness plans.

## Proposed Solution

FitBuddy is a web-based AI fitness assistant.

The user provides:

- Name
- Age
- Weight
- Fitness goal
- Preferred workout intensity

The application sends this information to Gemini AI.

Gemini generates a personalized 7-day fitness plan.

The system also provides nutrition or recovery guidance.

Users can provide feedback on their existing plan, and the AI can generate
an updated plan based on that feedback.

## Main Features

- Personalized 7-day workout plan
- AI-generated fitness recommendations
- Goal-based nutrition tips
- Recovery suggestions
- Feedback-based plan regeneration
- SQLite database storage
- FastAPI backend
- HTML/CSS user interface
- API endpoints
- Health check endpoint

## Target Users

The application is intended for general users who want structured fitness
guidance based on their goals and preferences.

## Expected Result

The final system should allow a user to enter fitness information and receive
