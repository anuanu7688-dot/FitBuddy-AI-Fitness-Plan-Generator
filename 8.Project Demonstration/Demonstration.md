2. Enter Name: Anu, Age 21, Weight 60, Height 165, Gender Female, Intensity Medium, Goal Weight Loss, Diet Vegetarian
3. Click Generate -> Shows 7-day plan with BMI 22.0, 1440 kcal, 96g protein + Nutrition + Recovery tip
4. Download txt

2. Enter same Name: Anu, Feedback: "knee pain, no squats, add more upper body"
