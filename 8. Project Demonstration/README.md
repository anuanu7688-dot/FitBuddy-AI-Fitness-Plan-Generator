# 8. Project Demonstration

## Demonstration Objective

The demonstration shows how FitBuddy generates and updates personalized
fitness plans using Gemini AI.

## Demonstration Flow

### Step 1

Open the FitBuddy application.

### Step 2

Enter the user's name.

### Step 3

Enter age.

### Step 4

Enter weight.

### Step 5

Select a fitness goal.

Example:

Weight Loss

### Step 6

Select workout intensity.

Example:

Medium

### Step 7

Click:

Generate Fitness Plan

### Step 8

The application displays a personalized 7-day fitness plan.

### Step 9

The application displays a nutrition or recovery tip.

### Step 10

Enter feedback.

Example:

"Add more cardio and include more rest days."

### Step 11

Click:

Update My Plan

### Step 12

The application displays the updated plan.

## Demonstrated Scenarios

### Scenario 1

Personalized 7-day fitness plan generation.

### Scenario 2

Feedback-based plan regeneration.

### Scenario 3

Goal-based nutrition or recovery recommendation.

## Expected Demonstration Result

The user should be able to interact with FitBuddy and receive AI-generated
fitness guidance through the web interface.
