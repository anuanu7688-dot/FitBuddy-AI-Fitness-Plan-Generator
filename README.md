# FitBuddy - AI Fitness Plan Generator

An AI app that generates personalized Diet and Workout plans using Gemini AI.

Features:
- BMI Calculator
- Indian Diet Plan
- Custom Workout Plan

Tech Stack: Python, Streamlit, Gemini AI

How to Run:
pip install -r requirements.txt
streamlit run app.py
